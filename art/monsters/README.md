# 怪物图鉴

和 `art/portraits/` 一个套路：把图片丢进这个目录，按怪物 id 命名。

```
art/monsters/
  wild_wolf.png        ← 文件名 = js/characters.js 里的敌人 id
  giant_dire_wolf.png
```

**文件名必须等于敌人 id**（见 `js/characters.js` 的 `ENEMIES`），
`node tools/gen-art.mjs` 会扫这个目录生成 `manifest.json`，
战斗里 `js/sprites.js` 的 `drawEnemy` 优先用图片，读不到就退回代码画的那只。

- **加删图片之后必须跑一次** `node tools/gen-art.mjs`
- 文件名对不上任何一个敌人 id，`gen-art.mjs` 会报错退出（游戏读不到那张图）
- 规格：建议 **512 × 512**，透明底，支持 `.png` / `.webp` / `.jpg`
- **底边 = 脚底**：图片按「脚底中心」对齐，和 `drawWolf` / `drawHumanoid` 的锚点一致，
  所以换成图片之后站位、缩放、血条位置都不用改。怪物脚下不要留空白。
- 怪物图没有表情差分，一个 id 一张

当前已定义的敌人 id：`wild_wolf`（野狼）、`dire_wolf`（凶狼）、`blood_wolf`（血狼）、
`giant_dire_wolf`（巨型凶狼）、`mutant_blood_wolf`（变异血狼）、
`angry_chick`（愤怒的小鸡）、`fierce_rabbit`（大凶兔）。
下面提示词里带别的文件名的，得先把那个怪物加进 `ENEMIES` 才会被读到。

共通风格建议：

> 中国网络游戏怪物图鉴插画，全身，四分之三侧面，深色背景，
> 赛璐璐上色，线条干净，无文字无 UI

## BOSS 等级体系（第16章原文，逐字）

> 在《命运》世界，BOSS的构成共分为1星级、2星级、3星级，以及领主级。
> 1星级的BOSS相当于普通怪物中的普通精英，能力超出同类的普通怪物1-2倍，
> 而两星级BOSS则是精英中的精英，能力要超出1星级的1-2倍，
> 三星级则是领地的首领……而领主级BOSS则是大片领地中的最高统治者。
> 而领主级BOSS以上，则是虽同样为BOSS，却比正常BOSS可怕无数倍的异兽——
> **仙灵之兽、天煌之兽、神玄之兽、圣灭之兽**。

> 当玩家到了很高的级别，组成一个庞大的团队后或许有可能战胜一个低级的仙灵之兽，
> 但天煌之兽的级别以后，对玩家而说，它们的存在可以用四个字来形容——**不可战胜**！

图鉴上的星级标记要按这个体系画：1星 / 2星 / 3星用金色星星，领主级以上另作标记。
