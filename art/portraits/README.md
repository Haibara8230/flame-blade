# 图片立绘

把图片丢进这个目录，游戏自动改用图片；没有的角色继续用 `js/portraits.js` 里
代码画的那张。**不需要改任何代码。**

```
art/portraits/
  kaito.png          ← 默认立绘，所有表情都用它
  kaito-angry.png    ← 可选：某个表情的专用图；没有就退回默认立绘
```

- 支持 `.png` / `.webp` / `.jpg`
- 表情名：`normal` `angry` `hurt` `cry` `shout` `smile`
- **加删图片之后必须跑一次** `node tools/gen-art.mjs` 重新生成 `manifest.json`，
  否则游戏读不到（和改完 `equipment-catalog.json` 要跑 `gen-equipment.mjs` 一个道理）

## 尺寸与构图：全身

- **建议 480 × 1280（3:8），全身站姿，头顶到脚底完整入画，透明底 PNG。**
- 头部落在画面顶部 **15% 以内**，脚底贴着底边——引擎按底边对齐把人「立」在舞台上。
- 半身图（如 300 × 360）**仍然支持**，不用改；两种会以不同方式显示：

| 图片高/宽 | 显示方式 |
| --- | --- |
| ≥ 1.6（全身） | 站在舞台左侧，脚被对话框挡住，对话框自己撑满 |
| < 1.6（半身） | 对话框里那个 126 × 136 的小框（`js/portraits.js` 代码画的那批就是这种） |

判断完全依据**图片自身的高宽比**（`js/main.js` 的 `FULL_BODY_RATIO`），
剧本和清单里都不用额外标一笔——换一张更长的图进来，显示方式会自己跟着变。

⚠ 卡入（cut-in）和角色卡用的是 `object-fit:cover; object-position:top`，
只截图片顶部。全身图在那两处会显示成「头 + 上半身」，这是预期的。

怪物 / BOSS 的提示词**不在这份文件里**，见 `art/monsters/README.md`。

## 立绘分三层

| 层 | 是什么 | 怎么画 |
| --- | --- | --- |
| ① 独立立绘 | 原文给了外貌描写、且反复出场的角色 | 一人一张，提示词见下文 |
| ② 通用路人 | 原文一句长相都没写的配角 | **六张共用图**，按性别 / 玩家还是 NPC / 是否黑西装 / 是否老年分 |
| ③ 不给立绘 | 原文里根本没有形体的（比如「系统」） | 纯文字，不占立绘位 |

第 ② 层是这次新加的。以前的做法是「宁可没有立绘也不要编」，结果一堆有台词的人
全程空着对话框。共用图解决的是**同一个问题的另一半**：不编具体的脸，但给一个
明确写着「这是个没有描写的路人」的通用形象。

> ⚠ 通用路人图本身也要标明它是通用的——画成半侧身、低对比、不给特写五官，
> 让玩家一眼看出「这个人原文没写长相」，而不是误以为这是某个特定角色的脸。

## 共通风格（每条提示词前面都加）

> 中国网络游戏小说角色立绘，**全身，站姿**，正面，头顶到脚底完整入画，
> 双脚在画面最底边，透明背景，3:8 竖长构图（480:1280），
> 赛璐璐上色，线条干净，无文字无 UI
