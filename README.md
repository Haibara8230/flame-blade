# 🐉 邪龙逆天 · 第一卷「永恒命运之刻」

> 一款**网游文风格**的「文字 + 图画」RPG。
> 纯前端实现（HTML5 Canvas + 原生 ES Module），**零依赖、可离线**运行。
> 所有美术（立绘、场景、战斗特效、精灵动画）都是**代码程序化绘制**的，没有任何外部图片素材。

```
「上有碧落，下有黄泉。」
```

> **这是什么**：本项目改编自网络小说《网游之邪龙逆天》（火星引力），
> 属于个人自用的同人作品，**未公开发布**。
> 事件顺序、人物、地名、设定数值**按原文**（`refs/` 下的原文，不进仓库）；
> 台词与场景文字是重写的——小说的叙述体塞进对话框读不了。
> 原著版权归作者所有。

## 🎮 如何开始

**方式一（推荐）**：双击 `启动游戏.cmd`
→ 自动在本机起一个静态服务器并打开浏览器。

**方式二（手动）**：
```powershell
node tools/serve.cjs 8123
# 浏览器打开 http://127.0.0.1:8123/
```

> ⚠️ 必须通过 http 打开。游戏使用 ES Module，直接双击 `index.html`（file://）会被浏览器的
> 跨域策略拦住。任何静态服务器都可以，例如 `python -m http.server 8123`。

**调试模式**：`http://127.0.0.1:8123/?debug=1` 会额外挂上自动化测试接口
（`__autoRun` / `__setScene` / `__partyJoin` / `__G` 等），供 `tools/` 下的脚本使用；正常游玩不需要。

## 🔢 数值体系（按原文三层结构）

`js/realm.js` 是唯一事实源。换算公式直接用原文给的战士公式。

### ① 自由属性 — 25 点，每项 4~10，升级继续加点

| 属性 | 换算 |
| --- | --- |
| 力量 | 物攻 +2 |
| 体质 | 生命 +10、防御 +1 |
| 敏捷 | 回避 +1、命中 +1 |
| 精神 | 魔攻 +2、魔法值 +10 |

### ② 固定属性 — 10 点，每项 0~10，**不随升级增长**

幸运 / 悟性 / 魅力。**幸运是真生效的**：原文系统警告「幸运为 0，爆率和暴击率会变到最低，
攻击时全部取攻击值的下限」——所以幸运 0 的角色**永不暴击，且每一刀的伤害浮动恒定取下限**。

### ③ 天赋属性 — 系统扫描，不可分配

反应力 / 感知力 / 专注力，常人平均 7~10；叶天邪 **72 / 53 / 42**（约七倍于常人）。
接进战斗：反应力 → 闪避，感知力 → 命中，专注力 → 异常抗性。
折算只算**超出常人的部分**且收益递减，所以常人基准处收益为 0，七倍很强但不会变成免疫一切。

> 角色创建是玩家真正要做的决定：自由 / 固定属性各三种取向，都真实生效。
> 可以照抄叶天邪（力10/体7/敏4/精4，魅10/幸0/悟0），也可以不。

### 主角当前状态

**没有职业**——按原文，职业赋予失败，整个新手期无职业，10 级才能转职，
邪龙系技能要到原文第 111 章才解锁。现有五招围绕反应力设计：

他**一个战斗技能都没有**。原文第9章：

> 「即使是0级的玩家，也会自带一个见习职业的见习技能。而全世界只有叶天邪一个例外，
> **他没有技能，没有职业**，只能以新手剑并不华丽的砍、劈、刺……」

所以指令只有普攻（砍／劈／刺）和全职业共有的**探知术**。
⚠ 此前配了「短剑斩／读招／投石／擦身反手／凝神」五个技能和一整条邪龙线，
全部是本项目编的，已删除。邪龙系技能要到原文第 111 章转职之后才存在。

活下来靠的是**反应力 72**（常人 7~10）折算出的闪避——原文里三只五级野狼
「连碰到没有碰到他」，全场唯一挨的一爪是他自己故意挨的。

### 战斗引擎

引擎侧的能力（大部分在当前八章里用不满，随剧情推进逐步启用）：

- **速度行动条**：全场共用一条行动条，速度决定涨条快慢，顶部显示接下来 8 个出手者。
- **推条 / 拉条**：技能可以带 `gauge: ±N` 直接加减目标的行动条，另有 `haste` / `slow` 状态。
- **回避 / 命中**：来自自由属性【敏捷】与天赋属性【反应力 / 感知力】。
- **格挡 / 弹反（概率）**：弹反全免 → 格挡 ×0.38 → 全额承受。
- **属性克制**：炎 / 冰 / 雷 / 暗 / 圣，打中弱点 1.5 倍伤害。
- **首领二阶段**：血量过半变身，攻击力上升。
- **目标选择**：攻击 / 技能 / 道具 / 治疗 / 复活都能指定单位。
- **两套资源**：主角用斗气（`rage`，开战为 0，靠出手与挨打积攒）；其余角色用术力类资源（开战满值，自然回复）。
