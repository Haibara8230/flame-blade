# 🐉 邪龙逆天 · 第一部 · 逆骨

> 一款**网游文风格**的「文字 + 图画」RPG。
> 纯前端实现（HTML5 Canvas + 原生 ES Module），**零依赖、可离线**运行。
> 所有美术（立绘、场景、战斗特效、精灵动画）都是**代码程序化绘制**的，没有任何外部图片素材。

```
「我死过一次了。这辈子轮到我说了算。」
```

> **这是什么**：本项目改编自网络小说《网游之邪龙逆天》（火星引力）的世界观设定，
> 属于个人自用的同人作品，**未公开发布**。剧情文本、数值设计、技能与关卡全部为原创，
> 沿用的是设定框架（龙魂 / 三转职业线 / 十一阶装备 / 公会争夺），不是原文。
> 原著仍在纵横中文网与微信读书连载发布，版权归作者所有。

## 🎮 如何开始

**方式一（推荐）**：双击 `启动游戏.cmd`
→ 自动在本机起一个静态服务器并打开浏览器。

**方式二（手动）**：
```powershell
node tools/serve.cjs 8123
# 浏览器打开 http://127.0.0.1:8123/
```

> ⚠️ 必须通过 http 打开。游戏使用 ES Module，直接双击 `index.html`（file://）会被浏览器的
> 跨域策略拦住。任何静态服务器都可以，例如 `python -m http.server 8123`。

**调试模式**：`http://127.0.0.1:8123/?debug=1` 会额外挂上自动化测试接口
（`__autoRun` / `__god` / `__state` 等），供 `tools/` 下的回归脚本使用；正常游玩不需要。

## ✨ 网游体系

改造的核心是把原本的单机剧情 RPG，换成一套**网游文**的成长与冲突结构。
战斗引擎（行动条 / 资源 / 格挡弹反 / 属性克制）沿用原有实现，这一层挂在它外面。

### 三转职业线 — `js/realm.js`

| 转 | 职业 | 等级 | 试炼 | 资源 |
| --- | --- | --- | --- | --- |
| — | 无职 | 1 | — | 术力 |
| 一转 | **逆骨邪龙** | 10 | 逆骨之守 ✔ 已实现 | 龙魂 |
| 二转 | **逆天邪龙** | 40 | （未实现） | 龙魂 |
| 三转 | **黄金龙神** | 70 | （未实现） | 龙魂 |

- **等级和试炼缺一不可**——光刷级转不了，光推剧情也转不了。
- 转职会换资源机制、换技能组、大幅提升数值。
- 另有四个**支线身份**（幻兽神使 / 深渊的爪皇 / 魔武圣 / 黎明圣射手），
  不替换主职业，作为被动常驻。数据已定义，解锁支线未实现。

### 十一阶装备

```
苍白之器 → 钢铁 → 青铜 → 白银 → 黄金 → 仙灵 → 天绝 → 神玄 → 亚·圣灭 → 圣灭 → 禁断之器
```

- **512 件**装备分布在 1~10 阶（每阶约 52 件），名称来自 `equipment-catalog.json`。
- 数值由 `js/loot.js` 派生：**阶位**决定档位与词缀条数，**主题**决定属性倾向，**类别**决定曲线。
- **掉落闸门看转职进度**，不是看剧情旗标：没觉醒龙魂的人，仙灵之器对他根本不显形。

  | 阶位 | 闸门 |
  | --- | --- |
  | 1~5 | 无 |
  | 6 仙灵 | 一转 |
  | 7~8 天绝 / 神玄 | 二转 |
  | 9~10 亚圣灭 / 圣灭 | 三转 |
  | 11 **禁断之器** | 永不掉落 |

- **禁断之器全服仅两件**，`weight: 0`，不进掉落池，只能由剧情授予：
  - **碧落黄泉**（刀剑）— 攻击自伤 6%，生命低于 40% 时攻击 +45%
  - **命运之刻**（护符）— 每场一次致命伤残血，可预读敌方下一次行动

### 等级与掉落

- 上限 **99 级**，分段经验曲线（1-9 冲刺 / 10-39 平稳 / 40-69 拉长 / 70+ 陡峭）。
- **等级压制双向生效**：越级击杀最多 +120% 经验，碾压低级怪收益迅速归零——
  想升级就得往打不过的地方走，而不是在安全区刷一晚上。

### 公会

四个势力（`js/realm.js` 的 `GUILDS`），态度各不相同：

| 公会 | 势力 | 态度 |
| --- | --- | --- |
| **天阙** | 100 | 敌对 — 第七区第一大公会，主张禁断之器必须归公会 |
| **九幽** | 88 | 不明 — 没有招募、没有频道，成员全是空白头像 |
| **玄冥** | 72 | 敌对 — 不抢首杀，只抢掉落 |
| **落霞** | 48 | 中立 — 散人联盟，人多但不齐 |

第四章的刷新点争夺是第一场正面公会战。争夺目标类型（刷新点 / 灵脉 / 传送阵 / 遗物）
已定义，后续章节会用到。

### 战斗核心

- **速度行动条**：全场共用一条行动条，速度决定涨条快慢，顶部显示接下来 8 个出手者。
- **推条 / 拉条**：行动条是可以打的——天痕的四连枪把目标往后打 22 点，
  仙儿的「灵息·牵」让全队抢先手，邪天的「龙吼·慑」把全体敌人往后推。
- **两套资源**：邪天用**龙魂**（开战为 0，靠出手 / 挨打 / 格挡积攒，越打越猛）；
  其余三人用术力类资源（开战满值，自然回复）。
- **龙魂三段解放**：25 / 60 / 100 三档，对应不同强度的解放技。邪天的强招几乎都要自伤——
  血爆自伤 8%、苍穹断自伤 30%，这是他的设计主轴。
- **格挡 / 弹反（概率）**：弹反全免 → 格挡 ×0.38 → 全额承受。
- **属性克制**：炎 / 冰 / 雷 / 暗 / 圣，打中弱点 1.5 倍伤害。
- **首领二阶段**：血量过半变身，攻击力上升。

### 角色

| 角色 | 定位 | 资源 | 特点 |
| --- | --- | --- | --- |
| **邪天**（叶天邪） | 近战 | 龙魂 | 开局最弱，越打越不讲理；强招全部自伤 |
| **仙儿**（璃仙儿） | 治愈 | 灵息 | 续航极强、爆发极弱；她的价值是让邪天敢用自伤技 |
| **天痕** | 游击 | 气劲 | 极快、极脆、会心极高；负责让敌人永远慢半拍 |
| **果果** | 术士 | 神识 | 极端玻璃炮，倍率全队最高，挨两下就倒 |

## 🗂️ 项目结构

```
game/
├── index.html                入口（Canvas + 所有 UI 层）
├── css/style.css             UI 样式
├── equipment-catalog.json    装备命名策划稿（512 件 / 11 阶）
└── js/
    ├── realm.js          ★ 世界观数据层：11 阶装备 / 三转职业 / 公会 / 经验曲线
    ├── characters.js       角色 / 技能 / 连携 / 敌人 / 道具 / 商店
    ├── chapter-rebirth.js★ 第一部剧情（序章 ~ 第四章）
    ├── story.js            流程装配
    ├── battle.js           战斗引擎（行动条 / 资源 / 弹反 / 状态）
    ├── loot.js             掉落：阶位 → 数值、主题 → 倾向、词缀
    ├── growth.js           属性点与天赋树
    ├── power.js            战力评估（面板显示 + 关卡配平共用同一套公式）
    ├── portraits.js        程序化 SVG 立绘（6 种表情差分）
    ├── sprites.js          场景 / 战斗精灵 / 特效
    └── equipment-data.js   ⚠ 生成产物，勿手改
```

**★** = 本次改造新增／重写的核心文件。
