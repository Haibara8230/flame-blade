# 🔥 炎之刃 · FLAME BLADE

> 一款**热血日漫风格**的「文字 + 图画」RPG 冒险游戏。
> 纯前端实现（HTML5 Canvas + 原生 ES Module），**零依赖、可离线**运行。
> 所有美术（人物立绘、场景、战斗特效、精灵动画）都是**代码程序化绘制**的，没有任何外部图片素材。

```
「我的剑，不会为仇恨而挥——它为守护而出鞘。」
```

---

## 🎮 如何开始

**方式一（推荐）**：双击 `启动游戏.cmd`
→ 自动在本机起一个静态服务器并打开浏览器。

**方式二（手动）**：
```powershell
cd game
node tools/serve.cjs 8123
# 浏览器打开 http://127.0.0.1:8123/
```

> ⚠️ 必须通过 http 打开。游戏使用 ES Module，直接双击 `index.html`（file://）会被浏览器的
> 跨域策略拦住。任何静态服务器都可以，例如 `python -m http.server 8123`。

**调试模式**：`http://127.0.0.1:8123/?debug=1` 会额外挂上自动化测试接口
（`__autoRun` / `__god` / `__state` 等），供 `tools/` 下的回归脚本使用；正常游玩不需要。

## 📱 手机上玩

**可以玩，而且专门做了手机适配。**

- **同一局域网**：在跑服务器的电脑上查内网 IP（`ipconfig`，形如 `192.168.1.7`），
  手机浏览器打开 `http://192.168.1.7:8123/`。首次点击屏幕会**自动尝试全屏**，
  也可点右上角 `⛶` 手动切换。
- **请横屏玩**：游戏是 16:9 横屏。竖屏时会弹出「请把手机横过来」提示页，
  横过来自动消失（无需刷新）。
- **手机端专属行为**：
  - 战斗全程只需要点指令按钮，**不需要任何时机操作**，也就不再有悬浮圆钮遮挡画面。
  - 一次触摸只算一次确认（修掉了触摸事件重复触发的问题）。
  - 对话框 / 指令栏 / 技能栏 / 商店按屏宽重排，超矮屏自动收起次要信息。
  - 禁用双击缩放、下拉刷新与页面回弹；兼容刘海屏安全区（`viewport-fit=cover`）。
  - 横屏按高度铺满并适度放大，但**不允许宽度溢出视口**——4:3 平板上溢出会把指令栏最右的按钮裁到屏幕外。
    非 16:9 的屏幕上宁可上下留黑边。
  > 注：下方截图 12~17 拍摄于旧版时机弹反系统，画面中的圆钮已随改版移除。
- **测试范围**：已用无头 Chrome 在 6 种手机/平板视口（iPhone 14 / Android / iPhone SE / iPad
  × 竖屏 / 横屏）+ 桌面 1280 下验证布局、触屏按键尺寸、点击推进剧情与触摸输入链路，
  全部通过且控制台无报错（见 `screenshots/12~17-*.png`）。
  **未在真机上实测。**
- **声音**：浏览器要求先有用户交互才允许播放，进游戏点一下屏幕即可。

### 战斗核心玩法

- **速度行动条**：全场单位（我方 + 敌方）共用一条行动条，`速度` 决定涨条快慢，
  谁先涨满谁出手。**速度高的单位能在慢速单位出手一次的间隔里行动两次**，
  画面顶部会显示接下来 8 个出手者。轮到谁就给谁下一条指令，一次只管一个角色。
- **推条 / 拉条 / 加速 / 迟缓**：行动条不是只能看，是可以打的——
  雷的「连突·四连枪」把目标的行动条往后打 22 点；苍的奥义让**全队立刻抢到先手**；
  凯的「焦炎·狮子奋迅」给自己挂加速（速度 ×1.6）；璃的「暴雪」有机会让全体敌人迟缓（×0.6）。
  敌方同样有：暴风雪会让你迟缓，终焉魔王的「终焉之刃」会把全队的条一起打回去。
  顶部的出手顺序条是实时重算的，条被动了立刻就能看出来。
- **资源：术力 / 怒气**：技能和奥义统一消耗资源，但**不同角色的资源来源不同**——
  苍 / 雷 / 璃 用**术力**（开战满值，每次自己出手自然回复）；
  凯 用**怒气**（开战为 0，靠攻击命中、挨打、格挡、弹反积攒，越打越燃）。
  奥义不再需要单独的槽，攒够资源即可发动，仍带专属 cut-in 演出。
- **格挡 / 弹反（概率）**：敌人每次命中会先按你的属性滚判定——
  **弹反**（伤害全免）→ **格挡**（伤害 ×0.38）→ 全额承受。
  概率来自角色基础值 + 装备（锁子甲、魔铠加格挡，疾风之靴加弹反）。
  选择**「格挡」指令**可让该角色在下次出手前大幅提升这两个概率，并额外积攒怒气。
- **属性克制**：炎 / 冰 / 雷 / 暗 / 圣。打中敌人弱点有 **1.5 倍** 伤害并弹出「弱点！」。
  魔性的首领怕圣属性——苍的「圣光·裁罪」就是为它们准备的。
- **连击多段**：连刃三连斩、四连枪、奥义五段斩等，每一段独立结算暴击与特效。
- **首领二阶段**：Boss 血量降到一半会**变身**，攻击力上升，头像血条泛红。
- **状态异常**：剧毒、灼烧、冰封、眩晕、封印、迟缓、再生、攻击↑、防御↑、加速 等。
  持续时间按**该单位自己的出手次数**计算。
  **封印**会让目标只能普攻 / 格挡 / 用道具（技能栏会禁用并说明原因）。

## 📖 故事（五章 · 四种结局）

| 章节 | 舞台 | 内容 |
| --- | --- | --- |
| 序章 + 第一章 | 灰烬之村 | 少年**凯**在燃烧的村庄失去父亲，第一次拔刀 |
| 第二章 | 黑之森 | 结识苍术士**苍**、猎人**雷**，净化被魔气侵蚀的森之守卫 |
| 第三章 | 极北之城 | 雪地里遇见魔王的女儿**璃**，取回圣剑·霜华 |
| 第四章 | 深渊魔城 | 四天王连战，璃的真相被揭开——**你的选择决定她的命运** |
| 第五章 | 终焉王座 | 与魔王决战，走向 TRUE / NORMAL / BAD / **SECRET** 四种结局 |

- **TRUE END**：在雪地里对璃伸出手、一路不放手。
- **NORMAL END**：松开了手，赢了战争，输了约定。
- **BAD END**：终焉之战倒下，世界被擦成一片白。
- **SECRET END（隐藏）**：终焉之战第一形态结束时**全队资源仍高于 55%**
  （打完还留着怒气与术力 = 仍有余力）→ 触发**限界突破**，解锁真·奥义。

## ✨ 特色系统

- **队伍**：凯（炎之剑士·**怒气**）/ 苍（苍蓝术士）/ 雷（疾风之枪）/ 璃（冰晶少女），
  各有独立立绘、成长曲线、技能树与格挡/弹反率。资源类型由 `ACTORS[x].resource` 决定，
  新增一个怒气型角色只需要在数据里多写一条，战斗代码不用改。
- **成长**：等级 + 经验 + 技能习得（按等级解锁）；**升级会立即回血回蓝**。
- **装备**：武器 / 护甲 / 饰品三槽位，除了攻防还会影响**格挡率 / 弹反率**，商店购买后可直接换装。
- **道具**：疗伤药、术力之泉、复苏之羽、封魔符、炎爆弹、遁形烟……
- **商店**：四个补给点（村庄 / 港町 / 北境 / 深渊前哨）。
- **存档**：右上角 `◇ 存档`（写入 localStorage），标题画面 `继续冒险` 读取。
- **音效与 BGM**：WebAudio 程序化合成（挥砍、暴击、格挡、升级、胜利小号、章节 BGM），无音频文件。

## 🧪 自检工具

```powershell
cd game
node tools/validate.mjs     # 剧情图连通性、引用完整性、结局可达性、资源与弱点校验
node tools/balance.mjs      # 每场战斗的轮数与生存力评估
node tools/battlesim.mjs    # 真的跑完几场战斗，查行动条卡死与奥义可达性
node tools/playthrough.cjs  # 无头 Chrome 全流程通关（需先起服务器）
```

`validate.mjs` 会检查：
- 每个场景是否都有出路（不会卡死）、所有 `goto/join/item` 引用是否存在；
- 四种结局是否都可达；
- 每条台词长度、技能威力是否缺失；
- 每个角色的 `resource` 合法、奥义消耗不为 0 也不超出资源池、习得等级不高于主线终盘等级；
- 敌人的 `weak` 属性存在，且队伍里真的有人打得出这个属性；
- **可达性**：每个商店都被某个可达场景引用、每件装备/道具都能买到或被发放、
  每个状态都有技能会施加、每个属性都有攻击技能能打出
  （专防「台词说给了、实际没给」这种只有真人玩到才会发现的问题）；
- 首领强度按**实际遭遇等级**换算后是否单调递增（基准值之间没有可比性）；
- 模拟主线经验，确认终盘等级落在设计区间。

## 🎨 关于「素材」

题目里提到素材可以上网找。这里选择了**全部程序化生成**，原因是：

1. **零版权风险** —— 不引入任何第三方图片/音频；
2. **完全离线** —— 断网也能跑，不依赖 CDN；
3. **风格统一** —— 立绘、精灵、UI 用同一套配色（炎橙 × 暗紫 × 霜蓝），更像一部完整的日漫作品；
4. **可动画** —— 精灵是矢量路径，能实时做受击白闪、蓄力前倾、突进位移、倒地等形变。

如果你想换成真实素材，只需把 `sprites.js` 里的 `drawHumanoid / drawEnemy / drawBackground`
替换为 `ctx.drawImage(img, ...)`，并保留相同的 `pose` 参数即可。
